# Redesign-Prototyp (Design-Quelle)

Klick-Prototyp aus Claude Design, unverändert aus
`DayOrganizer mobile app design.zip` (Stand 2026-09-26) übernommen.

- `DayOrganizer App.dc.html` — Markup, Stile und die gesamte Prototyp-Logik
  (Konstanten `ICONS`, `TYPES`, `TABS`, Funktionen `tageText`/`planText`,
  Klasse `Component` mit `renderVals()`).
- `support.js` — Laufzeit des Design-Tools; zum Öffnen im Browser nötig,
  für die Umsetzung inhaltlich irrelevant.

Lokal ansehen: beide Dateien im selben Ordner lassen und die HTML-Datei im
Browser öffnen. Die Pläne unter `docs/superpowers/plans/` verweisen auf diese
Dateien als „Prototyp“.
